О проекте

MiniBiz — небольшой проект по созданию полезных цифровых инструментов. Здесь нет огромной команды и офиса: это аккуратная коллекция программ, каждая из которых решает одну конкретную задачу и не требует сложной настройки.

Направления

  • MiniBiz Software — программы для Windows: работа с файлами, поиск, анализ, резервные копии.
  • MiniBiz Web Studio — создание сайтов: визитки, портфолио, лендинги, каталоги товаров.
  • MiniBiz Game Studio — разработка для Roblox: интерфейс, каркасы игр, скрипты.
  • MiniBiz Automation — автоматизация рутины: переименование, отчёты, преобразование файлов, тексты для товаров.
  • MiniBiz Digital Packs — цифровые наборы, которые собираются по мере готовности продуктов.

Как устроен каталог

Каждый товар описан одним блоком данных: название, направление, категория, описание, требования, инструкция, версия и поле цены. Разметка, фильтры и счётчики строятся из этих данных, поэтому новая позиция добавляется редактированием одного файла. Поле цены уже подготовлено, но оплата на сайте не подключена.

Как устроен сайт

Сайт — статический: это набор HTML-страниц, один файл стилей и несколько файлов JavaScript. Нет базы данных, нет регистрации и нет серверной части.

Принципы

  • Простота. Одна задача — один инструмент. Никаких лишних функций.
  • Прозрачность. Статусы указаны честно: «Готов» — только для проверенных продуктов, «В разработке» — если работа ведётся, «Скоро» — если это пока идея.
  • Приватность. Инструменты не отправляют ваши данные в интернет и не собирают статистику.
  • Безопасность. Программа для работы с файлами меняет что-либо только после подтверждения.

Чего здесь нет

  • Отзывов и рейтингов — пока их нет, они не выдумываются.
  • Счётчиков «10 000 пользователей» — такие цифры не публикуются без подтверждения.
  • Кнопок скачивания у товаров, которых ещё не существует.
  • Оплаты на сайте — платёжный сервис пока не подключён.
Проект развивается постепенно: сначала выпускается рабочий инструмент, затем он проверяется, и только после этого появляется в каталоге.
